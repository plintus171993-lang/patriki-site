# Сайт «Патрики Паб» — веселый-патрик.рф

Статический сайт (HTML + JS) на той же базе Supabase, что и приложение patriki-app.

## Страницы и SEO
У каждого раздела свой адрес — `/menu/`, `/delivery/`, `/booking/`, `/events/` и `/events/<повод>/` (birthday, corporate, wedding, banquet, rent, other), `/news/` и `/news/<id>/`, `/contacts/`. Старые ссылки вида `/#/events?k=birthday` (и возврат из оплаты Сбера) перенаправляются на новые сами.

- **Не правьте руками** `index.html`, `404.html`, `sitemap.xml`, `robots.txt` и папки разделов — их собирает `tools/build.mjs` из шаблона `src/template.html` и данных Supabase (меню, заведения, новости).
- Заголовки и описания страниц, тексты страниц праздников — `js/pages.js`.
- Сборку запускает GitHub Actions (`.github/workflows/build.yml`) при изменении исходников и каждые 30 минут, так что новость из админки появляется отдельной страницей в течение получаса.
- Локально: `node tools/build.mjs --offline` (меню из `js/seed.js`, заведения и новости из `tools/fixture.json`).
- Служебные страницы (корзина, оформление, кабинет, вход, статус заказа) закрыты от индексации.

- Меню, доставка с оплатой, бронь стола, вход по номеру телефона (Telegram-бот / звонок), карта гостя с QR — та же логика, что в приложении (`js/store.js`, `js/loyalty.js`, `js/config.js`, `js/seed.js` — копии из `patriki-app/www/js`; при изменениях там — скопировать сюда).
- Новости, акции и афиша — таблица `news`, правятся в админке приложения → вкладка «Сайт».
- Заявки на мероприятия (день рождения, корпоратив, свадьба, банкет, аренда зала) — `submit_event_request`, приходят в Telegram-чат паба и владельца, видны в админке → «Сайт».
- Документы (политика, оферта, согласие) — на https://patrikipab.ru/legal/.
